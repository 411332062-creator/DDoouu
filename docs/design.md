這份文件記錄設計稿裡的所有決定，做前端時以這份文件的數值為準。畫面上「有哪些元素、各自的行為」仍以 architecture.md 第 7 節為準，這裡只補上外觀。

名詞說明：

- **色碼**：用 `#` 開頭的六個字元表示一個顏色，例如 `#FFFFFF` 是白色。
- **px**：螢幕上的長度單位。
- **設計變數**：幫顏色取的名字（例如「主色」）。程式裡一律用名字，不直接寫色碼，這樣切換深淺色時只要換一組對照表。

## 1. 設計方向

- 淺色、深色兩套配色，可以切換。
- 版面像一般手機聊天 App：自己的訊息靠右、別人的靠左。
- 底色是帶一點綠的淺灰，主色是深青綠。除了主色以外，只有「提醒」用的琥珀色和「錯誤」用的紅色。
- 沒有漸層、沒有裝飾圖案。圖示全部是單色線條。
- 手機優先：設計稿以 390 × 844 px 的手機畫面為準。

## 2. 淺色深色切換

| 項目 | 決定 |
|---|---|
| 切換按鈕位置 | 歡迎畫面右上角；聊天室頂部列第一排右側 |
| 圖示 | 目前是淺色時顯示月亮（按了變深色）；目前是深色時顯示太陽 |
| 第一次打開的預設 | 跟隨手機或電腦的系統設定 |
| 記住選擇 | 使用者按過之後，記在瀏覽器裡，下次打開沿用 |
| 切換範圍 | 整個網站一起切換，包含歡迎畫面、聊天室和所有浮動視窗 |

後三項是設計稿表現不出來的行為，由我決定。設計稿裡每張畫面的切換按鈕只會切換那一張。

這個按鈕不在 architecture.md 第 7 節的畫面清單裡，是設計階段新增的元素。

## 3. 顏色

程式裡用左欄的變數名稱。

| 變數名稱 | 用途 | 淺色 | 深色 |
|---|---|---|---|
| `--bg` | 整頁底色、訊息區底色 | `#F1F4F3` | `#0E1412` |
| `--surface` | 頂部列、輸入區、面板、視窗的底色 | `#FFFFFF` | `#18201D` |
| `--text` | 主要文字 | `#17201D` | `#E8EEEB` |
| `--muted` | 次要文字：時間、說明、剩餘字數 | `#55625E` | `#A3B0AB` |
| `--line` | 分隔線、輸入框邊框 | `#D5DDD9` | `#2E3A35` |
| `--accent` | 主色：自己的訊息、主要按鈕、新訊息按鈕 | `#0F6E5C` | `#1F7A66` |
| `--on-accent` | 放在主色上面的文字 | `#FFFFFF` | `#FFFFFF` |
| `--accent-text` | 主色的文字版：別人的暱稱、文字按鈕 | `#0B5A4B` | `#6FD9C0` |
| `--bubble` | 別人的訊息底色 | `#FFFFFF` | `#212B27` |
| `--field` | 輸入框底色 | `#FFFFFF` | `#121917` |
| `--chip` | 日期分隔線、「已隱藏」標籤、選單裡的次要按鈕底色 | `#E4EAE7` | `#26312D` |
| `--disabled` | 不能按的按鈕底色 | `#C3CCC8` | `#3A4742` |
| `--warn-bg` | 提醒的底色：斷線、發太快、暱稱被拿走 | `#FFEFC9` | `#3B2E10` |
| `--warn-text` | 提醒的文字 | `#5C3B00` | `#F6D88F` |
| `--error` | 錯誤文字、錯誤的輸入框邊框、「清空所有資料」 | `#B3261E` | `#FF9A8F` |
| `--scrim` | 浮動視窗後面的半透明遮罩 | `rgba(15,25,22,.45)` | `rgba(0,0,0,.6)` |
| `--demo-bg` | 示範模式提示的底色 | `#E3E9F7` | `#1E2740` |
| `--demo-text` | 示範模式提示的文字 | `#27365E` | `#C5D0F2` |

使用規則：

- 不能按的按鈕：底色 `--disabled`，文字 `--muted`。
- 被鎖住的輸入框：整個變成六成不透明。
- 隱藏後的提示條顏色是反過來的：底色用 `--text`，文字用 `--bg`。
- 文字和底色的搭配只用上表列出的組合，這些組合是照「文字要夠清楚」的標準挑的。

## 4. 字體與文字大小

- 字體：**Noto Sans TC**（思源黑體），從 Google Fonts 載入，用到 400（一般）、500（中等）、700（粗體）三種粗細。載入失敗時退回系統內建字體。
- 內文基準：15 px，行高 22 px。

| 用在哪裡 | 大小 / 行高 | 粗細 |
|---|---|---|
| 歡迎畫面的聊天室名稱 | 30 / 40 | 700 |
| 頂部列的聊天室名稱 | 18 / 26 | 700 |
| 面板與視窗的標題、使用者選單的暱稱 | 17 / 24 | 700 |
| 主要按鈕（進入聊天室） | 17 | 700 |
| 歡迎畫面的暱稱輸入框 | 18 | 500 |
| 歡迎文字、空白狀態、選單與視窗的按鈕、其他輸入框 | 16 / 24 | 400–700 |
| 訊息內容、名單裡的暱稱 | 15 / 22 | 400 |
| 頂部列的線上人數與我的暱稱、提醒文字、錯誤文字、文字按鈕 | 14 / 20 | 500 |
| 別人訊息上方的暱稱 | 13 | 700 |
| 說明文字、缺漏提示 | 13 / 20 | 400 |
| 示範模式提示、日期分隔線、剩餘字數、暱稱字數 | 12 / 18 | 400 |
| 訊息旁的時間 | 11 / 16 | 400 |

所有輸入框的文字至少 16 px。小於 16 px 時 iPhone 會在點輸入框時自動放大整個畫面。

## 7. 各畫面的外觀

### 7.1 歡迎畫面

由上到下：

1. **示範模式提示**：整條橫幅，文字置中。只在階段一出現。
2. **淺色深色切換按鈕**：靠右。
3. 以下內容在剩餘空間裡垂直置中、靠左對齊：
   - **標誌**：56 × 56 的主色方塊，左下角是尖的（像對話框），裡面三個白點。
   - **聊天室名稱**
   - **歡迎文字**，依狀態不同：

     | 狀態 | 外觀 |
     |---|---|
     | 新使用者 | 一般文字 |
     | 回訪者 | 一般文字 |
     | 暱稱被拿走 | 琥珀色提醒框 |
     | 載入中 | 載入圈加次要文字 |
     | 連線失敗 | 琥珀色提醒框，右側有「重試」膠囊按鈕 |

   - **暱稱輸入框**：上方有標籤「你的暱稱」。邊框 2 px；有錯誤時邊框變紅色。
   - 輸入框下方一排：左邊是錯誤訊息（紅色）和字數「5 / 12 個字」，右邊是「重新抽一個」文字按鈕。
   - **「進入聊天室」按鈕**：整排寬，主色底白字。不能按時變成灰底。
   - **提醒文字**：次要文字顏色。

載入中和連線失敗時，輸入框和「重新抽一個」都鎖住，「進入聊天室」是灰的。

### 7.2 聊天室畫面

**示範模式提示**：最上方的橫幅，只在階段一出現。

**頂部列**（底色 `--surface`，下方一條分隔線），分兩排：

- 第一排：聊天室名稱靠左，淺色深色切換按鈕靠右。
- 第二排：線上人數靠左（人像圖示加「6 人在線」，主色文字）；我的暱稱靠右（暱稱加鉛筆圖示）。暱稱太長時用「…」截斷，最寬 220 px。

**連線中斷提示**：頂部列正下方的琥珀色橫條，圖示加文字，置中。

**訊息區**（底色 `--bg`）：

| 元素 | 外觀 |
|---|---|
| 別人的訊息 | 靠左。底色 `--bubble`，有 1 px 邊框。暱稱在上方，主色粗體，可以按。時間在訊息右側、對齊底部 |
| 同一人連續發的訊息 | 第二則起不顯示暱稱，緊接在上一則下方 |
| 我的訊息 | 靠右。主色底白字，沒有邊框，沒有暱稱。時間在訊息左側、對齊底部 |
| 訊息內容 | 保留換行；長字串強制換行；網址和其他文字外觀完全相同 |
| 過長訊息 | 最多顯示 12 行，超出的部分裁掉，下方有「顯示全部」文字按鈕（主色、有底線） |
| 日期分隔線 | 置中的小膠囊，底色 `--chip` |
| 「只保留最近 24 小時的訊息」「中間有較早的訊息未顯示」 | 整排寬、文字置中，上下各一條虛線 |
| 載入更舊訊息 | 置中，載入圈加文字 |
| 空白狀態 | 在訊息區正中央，對話框圖示加一行文字 |
| 新訊息按鈕 | 浮在訊息區底部中央，主色膠囊，往下箭頭加「有 3 則新訊息」，有陰影 |
| 隱藏後的提示條 | 浮在訊息區底部，左右各留 12 px。左邊「已隱藏 （暱稱）」，右邊「復原」（粗體、有底線） |

**輸入區**（底色 `--surface`，上方一條分隔線）：

- 發太快時，最上面多一條琥珀色提示，文字置中。
- 輸入框和發送按鈕並排，對齊底部。輸入框是膠囊形，隨內容長高，最多 4 行。
- 發送按鈕是 44 × 44 的圓形，主色底白色箭頭；不能按時變灰。
- 最下面是剩餘字數，靠右對齊到輸入框的右緣。

### 7.3 線上名單面板

從底部滑出，後面是半透明遮罩，最高佔畫面的 82%，內容超過時在面板內捲動。

- 標題列：「在線上（6）」靠左，關閉按鈕靠右。
- 名單：每列高 44 px，列與列之間一條分隔線。
  - 我自己排第一，粗體，後面接次要文字的「（我）」，不能按。
  - 其他人整列都可以按。
  - 被我隱藏的在線者：文字是次要顏色，後面有「已隱藏」小標籤。
- 「已隱藏的人」區：上方有一條較粗的分隔，小標題是次要顏色。每列左邊暱稱，右邊「取消隱藏」膠囊按鈕（有邊框、主色文字）。

### 7.4 使用者選單

從底部滑出，後面是半透明遮罩。由上到下：

1. 對方的暱稱（粗體）
2. 一行說明（次要文字）
3. 動作按鈕：整排寬，底色 `--chip`，圖示加文字。依狀態顯示「隱藏這個人」或「取消隱藏」
4. 「關閉」文字按鈕

### 7.5 改名視窗

浮在畫面上半部（距離頂端 120 px，左右各留 20 px），後面是半透明遮罩。放在上半部是為了手機鍵盤彈出時不會被擋住。

由上到下：標題、輸入框標籤、輸入框、錯誤訊息、說明文字、一排兩個等寬按鈕（左「取消」有邊框，右「確定」主色底）。

有錯誤時輸入框邊框變紅色。

### 7.6 測試面板

浮在聊天室右下角、輸入區上方，寬 236 px，有邊框和陰影，後面沒有遮罩。

- 標題列：「測試面板」加收合按鈕。
- 六個按鈕直排，都有邊框。最後一個「清空所有資料」是紅色邊框和紅色文字。

### 7.7 分頁標題

- 平常：`匿名聊天室`
- 頁面在背景時有新訊息：`(3) 匿名聊天室`

## 10. 做前端時要注意

1. **設計稿是外觀參考，不是程式**。設計稿的檔案格式是畫布專用的，不能直接拿來當前端程式。前端照 architecture.md 第 11 節的資料夾結構，用 React 重新寫，外觀照這份文件。
2. **顏色一律用第 3 節的變數名稱**，不直接寫色碼。兩套配色各定義一次，切換時只換對照表。
3. **設計稿裡的範例資料不是規格**：暱稱（愛睏的水獺、害羞的石虎等）、訊息內容、線上 6 人、時間，都只是示意。
4. **聊天室名稱暫定「匿名聊天室」**，正式名稱還沒決定。前端把它放在一個地方統一設定，方便之後修改。
5. **設計稿沒有畫出來、要照 architecture.md 做的行為**：
   - 手機鍵盤彈出時，輸入區貼在鍵盤上方。
   - 載入更舊訊息後畫面不跳動。
   - 浮動視窗的滑出和消失動畫。設計稿是靜態的，動畫由前端決定，以簡短、不干擾為原則；使用者的系統設定為「減少動態效果」時不播放動畫。
   - 發太快的倒數、隱藏後提示條幾秒後自動消失。
6. **設計稿只畫了部分畫面的深色版**（歡迎畫面和聊天室各一張）。其餘畫面的深色版照第 3 節的對照表套用，每張設計稿上的切換按鈕可以預覽。
7. **這份設計稿發布後沒有逐張檢查過顯示結果**。做前端前請先打開畫布看一遍；如果畫布和這份文件有出入，以這份文件的數值和 architecture.md 的行為為準，並回頭修正畫布。
